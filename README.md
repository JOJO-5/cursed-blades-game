# 环刀旅者 (Cursed Blades)

2D俯视角暗黑可爱像素风肉鸽游戏。玩家控制像素角色在地图中移动，角色周围有武器持续环绕旋转，环绕武器碰到敌人后自动造成伤害。

## 快速启动

```bash
cd game
python3 -m http.server 8888
# 浏览器打开 http://localhost:8888
```

也可部署到任意静态服务器（如 GitHub Pages）。

## 技术栈

- 纯 Vanilla JavaScript（无框架、无游戏引擎）
- HTML5 Canvas 渲染
- Web Audio API 音效（程序生成音调，无需音频文件）
- localStorage 存档
- CSS 响应式适配（cover策略，支持手机竖屏和电脑横屏）

## 操作方式

### 电脑（键盘）

| 按键 | 功能 |
|------|------|
| WASD / 方向键 | 八方向移动 |
| 空格 | 闪避（短暂无敌+加速） |
| ESC / P | 暂停 |
| 1 / 2 / 3 | 升级时快速选择 |
| 鼠标点击 | 菜单/升级/剧情交互 |

### 手机（触屏）

| 操作 | 功能 |
|------|------|
| 左侧屏幕拖拽 | 虚拟摇杆移动 |
| 右侧屏幕点击 | 闪避按钮 |
| 右上角图标 | 暂停 |
| 点击 | 菜单/升级/剧情交互 |

## 游戏流程

```
开始界面 → 剧情对话 → 进入荒废村庄 → 移动并自动攻击敌人
→ 敌人死亡掉落经验 → 拾取经验并升级 → 三选一升级
→ 遇到宝箱/宝箱怪 → 获得武器或强化 → 遭遇精英怪
→ 挑战Boss(诅咒骑士) → 通关结算 → 解锁并保存 → 重新开始
```

## 游戏特点

- **环绕武器构筑**：武器围绕角色旋转，自动碰撞攻击，支持多武器、多分身
- **10种武器**：铁剑、战锤、镰刀、弓箭、火球、飞刀、灵魂弹、盾牌、炎之环刃、虚空环刃
- **10种升级**：伤害、攻速、武器数量、旋转速度、范围、穿透、暴击、移速、生命、回复
- **12种敌人**：5种普通近战、2种远程、2种精英、宝箱怪、Boss
- **宝箱系统**：普通宝箱、稀有宝箱、宝箱怪（伪装→暴露→战斗→稀有奖励）
- **Boss战**：诅咒骑士，多阶段，召唤仆从，狂暴模式
- **剧情系统**：关卡开始、Boss出现、通关剧情
- **本地存档**：自动保存进度，支持继续游戏

│   ├── core.js         # 数学工具/输入管理/资源加载/音频/RNG

│   ├── enemies/        # 敌人
│   ├── bosses/         # Boss

│   ├── items/          # 道具（经验宝石/宝箱/心）
