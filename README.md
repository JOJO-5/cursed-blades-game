# 环刀旅者 (Cursed Blades)

暗黑可爱像素风 2D 俯视角肉鸽生存游戏。玩家控制旅者在诅咒地图中移动，武器会自动环绕、发射、追踪、释放光环或召唤同伴，与不断刷新的敌潮和 Boss 战斗。

在线预览：<https://jojo-5.github.io/cursed-blades-game/>

## 当前状态

`v0.4.0-preview`，核心战斗闭环、三关流程、升级构筑、宝箱奖励、武器进化、本地存档和 GitHub Pages 自动预览已接入。

最近重点优化：

- 全图经验磁铁会按实际连升次数逐个弹出升级奖励，不再吞多级强化。
- 后期武器栏会自动缩小/换行，避免挤到摇杆和闪避按钮区域。
- 玩家撞到矩形障碍时会按进入方向推出，减少“看着能过但被卡住”的感觉。
- 怪物连续卡在边缘或障碍物时会自动侧向脱困。
- 升级卡池不再每次强塞武器卡，改为高权重概率出现；卡片描述会显示当前等级、下一级和明确数值收益。

## 快速启动

这是纯静态项目，直接用本地静态服务器打开即可。

```powershell
cd D:\mengfanliuFile\dev\cursed-blades-game
python -m http.server 8888
```

浏览器打开：

```text
http://localhost:8888
```

验证项目：

```powershell
npm test
```

测试会检查 JS 语法、配置结构、资源清单、PNG 文件、布局 helper、碰撞、存档恢复、经验磁铁、武器升级、召唤物和 GitHub Pages 相关关键路径。

## 核心玩法

游戏节奏类似生存肉鸽：

```text
开始游戏 → 剧情进入关卡 → 自动武器战斗 → 击杀敌人掉落经验
→ 拾取经验升级 → 三选一强化 → 寻找宝箱/击败宝箱怪
→ 构筑武器和遗物 → 精英敌潮 → Boss 战 → 进入下一关
```

当前内容：

- 3 个关卡：荒废村庄、地下矿洞、地狱熔渊。
- 38 种武器：基础武器、扩展武器、召唤武器和 3 种进化武器。
- 26 种升级：普通属性、稀有遗物、构筑联动、前置条件和最大等级。
- 31 种敌人：普通怪、远程怪、冲刺怪、精英、宝箱怪和 Boss。
- 宝箱系统：普通宝箱、稀有宝箱、可疑宝箱/宝箱怪。
- 稀有掉落：全图经验磁铁，可以一次吸收地图上所有经验。
- 本地存档：暂停菜单可保存退出，之后继续游戏。

## 构筑系统

武器分为多种标签：

- 环绕：围绕玩家旋转，适合近身清怪。
- 远程 / 弹幕：定时发射投射物，适合安全输出。
- 追踪：自动锁定敌人。
- 光环：持续影响周围区域。
- 召唤：生成可见同伴自动作战。

升级卡会根据当前武器标签显示“适配”“进化线”等提示。武器强化会展示明确收益，例如伤害、范围和环绕武器的视觉/命中体积提升。

## 技术栈

- Vanilla JavaScript，无前端框架。
- HTML5 Canvas 渲染。
- Web Audio API 程序化音效。
- localStorage 存档。
- 静态资源清单驱动加载。
- GitHub Actions + GitHub Pages 自动验证和部署。
